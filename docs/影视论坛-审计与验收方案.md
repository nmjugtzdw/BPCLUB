# 影视论坛：独立审计与验收方案

> 本文定义门禁和证据，不表示已完成审计或用户签收。审计者应独立核对当前代码、配置与结果；开发者的报告可作线索，不直接作为独立验证结论。

## 1. 角色与结论

开发 Agent 实现与自测；审计 Agent 基于阶段范围核查并重放关键测试，记录可复现问题；用户决定最终验收。开发与审计优先不同执行者；如只能同一执行者，明确注明不具独立性。任何第三方不得代用户签字。

每项记录：编号、严重度（P0 阻断/数据安全；P1 主要功能或权限；P2 一般功能与兼容；P3 体验）、位置、前置条件、复现、预期/实际、影响、修复和复验结果。结论为通过 / 不通过 / 证据不足；未验证不能标通过。P0/P1 未闭环不得签收；P2/P3 需用户明确接受且登记。

## 2. 通用门禁

| 项 | 必要证据 |
|---|---|
| 范围 | 当前代码、变更文件、需求逐项映射；无无关扩展 |
| 功能 | 真实 HTTP/浏览器请求与结果，覆盖正常、空值、404 和失败分支 |
| 数据 | 隔离测试库、迁移和回滚/恢复记录；数据与账号隔离 |
| 安全 | 未登录、普通用户、管理员及跨账号访问对照；CSRF、XSS、SQL 注入、限流与会话检查 |
| UI | 桌面/移动视口截图及人工走查，键盘焦点、主题及错误提示 |
| 剧透 | 首页、详情、作品页、搜索、分享摘要、无 JS 的对照检查；标记内容默认不进入公开预览 |
| 内容与版权 | 测试数据标注；影片元数据、图片、文本和外部 API 的来源及使用条件记录 |
| 运维 | 实际版本、隔离路径、备份/恢复、最小权限、生产变更审批和回滚 |
| 记录 | 命令、时间、退出码、测试数量、日志/截图路径和未验证事项 |

## 3. 核心测试场景

1. 首页/分类/搜索：排序、分页、空状态、异常关键词、重复名称、无权限内容不显示；不存在的作品与帖子返回 404。
2. 登录注册：重复账号、弱密码、错误凭据、退出、会话失效及暴力请求限制；密码不得明文保存或写入日志。
3. 发布与评论：必填、长度、恶意 HTML、跨账号编辑/删除、CSRF 与异常提交；用户不能自行赋予管理员权限。
4. 剧透：同一内容在帖子标题、列表摘要、作品页、搜索结果、分享 meta、API/HTML 和禁用 JS 时逐项核对；默认内容不泄露，授权展开后可读。单纯 CSS 隐藏而原文已出现在公开预览不算通过。
5. 审核与举报：普通用户不能访问管理界面或 API；管理员可处理举报；待审核/隐藏/删除内容各入口一致；日志记录操作人和对象，不记录密码。
6. 数据迁移：隔离库执行全新迁移、回滚、重建和真实备份恢复；失败时不影响现有生产数据库，记录版本、命令与结果。
7. UI：小屏与桌面无遮挡、键盘操作可见焦点、表单错误可关联；亮暗主题及对比度检查。

## 4. 上线前独立专项

- 复核运行环境、项目目录与数据库账号隔离；部署不修改其他站点，不执行未经确认的服务重启或共享组件升级。
- 权限与安全审查、限流验证、异常处理、日志保护、备份恢复演练；独立测试账号及生产密钥不可混用。
- 用户协议、隐私政策、版权投诉、举报和内容审核流程；实际业务涉及的备案、服务资质及素材使用条款由负责人核实。
- 回滚方案包含代码版本、数据库兼容与恢复点；真实演练只在隔离环境进行。
- 核验域名、对外文案、公开仓库敏感信息；发布、生产变更及推送均单独取得用户明确指示。
