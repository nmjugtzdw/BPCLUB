# 看完聊 · 交互原型

这是独立的静态原型，不替换旧工程。直接在浏览器打开 `index.html` 可查看首页；点击第一条示例话题可查看静态详情，搜索与分类仅筛选本页虚构示例。

不包含真实账号、数据存储、发帖、评论、后台、数据库或影视资源；“看完聊”是候选名称。原型中的折叠仅展示交互：`details` 内文本仍在 HTML 中，**不是符合项目剧透防泄露门禁的服务端实现**。后续 Agent 不得以原型声称完成 P00/P01 验收或安全测试。

正式技术路线、原有项目迁移和部署仍待用户确认；执行规划见 `../../docs/影视论坛-分阶段实施与任务清单.md`，审计见 `../../docs/影视论坛-审计与验收方案.md`。没有授权前不要覆盖 V2 源码或对外部署。
