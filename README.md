# 看完聊

> 名称暂定，最终名称与视觉标识仍待确认。

## 这是什么

一个聊电影和电视剧的地方。看完一部作品，想说说感受、讨论剧情、或者找人推荐下一部，都可以来这里。首页以帖子列表为中心，不追求收录多少影片，只在意围绕一部作品有没有真实、值得看的讨论。

## 现在能看到什么

网站目前还在筹备阶段。`kwl.zzzmxxkj.com` 已经可以打开，看到的是一张**首页样张**：列表里的作品、讨论、作者和时间**全部是虚构示例**，只用来说明版式与阅读体验，不代表真实内容或真实用户。

样张上还看不到的东西：账号、发帖、评论、搜索、作品资料页、管理后台。这些入口都标着「筹备中」，点了不会有反应——它们还没做，不是坏了。

## 现在还不能做什么

- 不能注册、登录，也不能发帖或评论。
- 不能搜索真实影视资料，也没有作品库、评分或排行榜。
- 不提供影片播放、音频、下载或任何资源链接。
- 首页样张上的分类入口只是示意，点了不会跳转，也不会保存任何操作。

## 接下来的打算

准备先做首页、作品资料、帖子与评论、搜索，以及账号和剧透提示。讨论剧情时，标记为剧透的内容会先遮挡，需要读者主动展开才看得到；列表、摘要和分享预览都不会提前泄露。这些功能**目前都还没上线**。

首批话题会由真实用户或编辑提供，不会编造用户、评论、评分或活跃度；任何测试数据都会醒目标注为演示。

## 说明

这里不托管、不播放、不分发影视内容，也不抓取或转载未经许可的海报、剧照、台词与影评。正式开放前会先完成内容审核、举报处理与账号管理的相关准备。
